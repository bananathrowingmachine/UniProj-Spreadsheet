UniProj-Spreadsheet
=

This was a multi-week long project to mainly get students used to doing a multi week long project (this was our first), and it was to build a fully functional spreadsheet from (mostly) scratch. Due to how the class was structured, each part was generally a week long assignment with a few exceptions, but luckily the idea of building a spreadsheet as a whole is rather simple, so there is no assignment instructions PDF for this as mashing the details of each week together would be a rather complex process, just to finally say "This is a simple spreadsheet".

Contributors
=
Like most school projects, not everything was done by me, however do note that this project is extra special in where I was helped and where I wasn't being very unique.
For this class, the professors provided us with skeleton code sometimes. If they did I edited their contribution to look similar to this:

```bash
Written by [redacted] for CS [redacted], September 2013
Update by Profs [redacted] and [redacted], Fall 2021, Fall 2024
     - Updated return types
     - Updated documentation
Finished by bananathrowingmachine, Oct 12, 2024
```

However as mentioned they were skeleton files, so the vast majority of the work in them is mine. 

Additionally, the final part of the project, the GUI, was optionally a pair programming assignment, which I chose to do. So a decent portion of the GUI stuff has a different redacted credits, along the line of this:

```bash
Made by bananathrowingmachine and [redacted], Oct 18 2024
```

This is seperate from the skeleton files, where I did about half of the work (in my opinion a little less). Additionally, it was decided pretty early on between the 2 of us that we'd be using all of my spreadsheet code to build the GUI on, so that's why the rest of it is mine.
